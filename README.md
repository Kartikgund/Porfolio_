# Kartik Gund — Portfolio

A single-page personal portfolio built with plain HTML, CSS and JavaScript (Tailwind-free, no build step).

## Run it

Just open `index.html` in any browser — no server or build process required.

```
portfolio/
├── index.html          # everything: markup, styles, and scripts
├── assets/
│   └── resume/
│       └── Kartik_Gund_Resume.pdf   # powers the "Download Resume" button
└── README.md
```

## Notes

- All content (experience, projects, skills, education, certifications, contact info) is sourced directly from the attached resume — nothing was invented.
- The "Download Resume" button links to the actual PDF in `assets/resume/`.
- Respects `prefers-reduced-motion` and is fully responsive from 375px to 1920px+.
